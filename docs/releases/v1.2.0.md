# SipTime v1.2.0

SipTime v1.2.0 expands reminder control, improves first-run setup, and strengthens accessibility and release reliability.

## Highlights

- Pause reminders for 30 minutes, 1 hour, 2 hours, or until tomorrow.
- Resume a temporary pause immediately without changing the saved schedule.
- Skip the next scheduled reminder while keeping later reminders intact.
- Choose quick interval presets for 30, 45, 60, or 90 minutes.
- Configure fixed reminders and quiet hours with an accessible 12-hour time wheel.
- Complete a guided first-run setup with notification testing.

## Accessibility and usability

- Improved keyboard navigation and focus management.
- Added screen-reader labels, live status announcements, and error focus.
- Added reduced-motion, increased-contrast, and forced-colors support.
- Increased interactive target sizes for touch and coarse-pointer devices.
- Preserved 24-hour `HH:mm` values internally while displaying readable 12-hour times.

## Engineering and release quality

- Added automated tests for scheduling, onboarding, interval presets, and time conversion.
- Added GitHub Actions validation for tests, lint, website builds, extension builds, and release packaging.
- Added deterministic Chrome Web Store ZIP generation.
- Added version synchronization, package-content validation, and SHA-256 checksums.
- Added tag-based GitHub Release publishing.

## Privacy and permissions

SipTime continues to operate locally in the browser. Version 1.2.0 adds no new extension permissions and does not require an account, analytics, or a backend service.

## Upgrade notes

Existing reminder settings remain compatible. After updating, open SipTime and review the new pause, skip, scheduling, and accessibility controls.
